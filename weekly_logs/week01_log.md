# 3. Key Decisions

- The project will strictly follow the official CartFlow Lakehouse architecture:
  **Sources → Bronze → Silver Candidate → Data Quality → Trusted Silver → Gold → Power BI.**

- GitHub will be used for version control, documentation, weekly evidence, and project tracking throughout the internship.

- Power BI dashboards will consume data only from the Gold layer.

- AI assistance will be limited to learning, debugging, documentation, and explanation. All generated content will be manually reviewed and verified before submission.
